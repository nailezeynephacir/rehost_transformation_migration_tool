Program çalıştırıldığında akış şöyledir:

original/ klasörünü tara
            ↓
rehost/ klasörünü tara
            ↓
Aynı relative path'e sahip dosyaları eşleştir
            ↓
Her dosyayı parser.py ile analiz et
            ↓
Rehost içindeki #if bloklarını bul
            ↓
Hangi branch'in original koddan geldiğini belirle
            ↓
Güvenli dönüşümleri transformations listesine ekle
            ↓
Sadece rehostta bulunan dosyaları support file olarak sakla
            ↓
rehost_transformations.json oluştur
            ↓
--report verilmişse extraction_report.txt oluştur


JSON kabaca şöyle olur:
{
  "transformations": [
    {
      "id": "conditional_1",
      "file": "main.c",
      "scope": "function",
      "match": "uint8_t value = (*VALUE_ADDRESS);",
      "replacement": "#ifndef TEST\n..."
    }
  ],
  "support_files": [
    {
      "path": "shared_memory.c",
      "content": "..."
    }
  ]
}



iki falan filan için gideceğim fonks -> select_matching_original_branch (helper) - extract_transformations(extraxr)
